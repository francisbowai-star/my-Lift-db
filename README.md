# My Lift - Inspirational Quotes

A simple web app that lifts your spirit with daily inspirational quotes.
**Live demo:** https://my-lift-db.vercel.app

## Features
- 🎲 Random inspirational quotes
- 🔍 Search / Categories
- 📋 Copy and share quotes

## Tech Stack
- Next.js / Vercel
- Supabase / Database

## How to run locally
```bash
npm install
npm run dev
